These files contain code and data for the submission of the paper "Ultrasonic signals support a large-scale communication network in wild mice". 

- code 
-- classifier 
This is the code used to fine-tune the ResNet18 to classigy the group accents of the mice. There is no data associated as these represent more than 15000 .wav files. 
-- stats
These are the R codes used to do statistics on the passive acoustic monitoring and the playbacks part (explain in Methods).
Please note that the paths correspond to the authors' computer, and that the results of the models may present slight differences with the ones in the manuscript due to the MCMC random sampling.

- data
-- pam
These files are the research data asssociated with the PassiveAcousticMonitoring.R script for statistics.
-- playbacks
These files are the research data asssociated with the Playbacks.Rmd script for statistics.
